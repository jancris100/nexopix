# Nexopix

Middleware de agentes de IA para Instagram y Facebook, conectado por API, con aprobación humana.

Proyecto del track AI Operators de Dojo AI Hackathon (20 al 22 de noviembre de 2026).

## Estado al iniciar el hackathon

La etiqueta `inicio-hackathon` marca lo que existía antes del 20 de noviembre: la página pública y un panel con un
pipeline **simulado**. No había agentes reales, base de datos ni publicaciones.

## Desarrollo

```bash
npm install
npm run dev
```
